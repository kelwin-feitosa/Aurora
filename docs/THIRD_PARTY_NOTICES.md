# Fontes e licenças de terceiros

**Nenhum trecho de código-fonte de outro repositório foi incorporado por cópia nesta implementação.** Inspiração de arquitetura, ideias e padrões de sistemas públicos não implica licença sobre repositórios alheios.

Foram analisados conceitualmente: `annazeng/email-to-calendar` (MIT no commit analisado na 0.2/0.3), `postalsys/postal-mime` (licença permissiva, não incorporado), `wanasit/chrono` (não incorporado), `activepieces/activepieces` (licenciamento misto para componentes Enterprise, não incorporado), `n8n-io/n8n` (Sustainable Use, não incorporado). Não incluir ou redistribuir binários de nenhuma dessas ferramentas nesta versão.

Ferramentas de desenvolvimento pretendidas: TypeScript e Wrangler; versões declaradas em `package.json`, instalação/lockfile ainda pendentes de rede. O runtime Worker usa Web APIs nativas. Se bibliotecas externas forem introduzidas, revisar licença, CVEs e reproduzibilidade antes de distribuir.
