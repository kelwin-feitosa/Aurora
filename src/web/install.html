Seu espaço acadêmico, no seu controle.

Este assistente orienta a instalação do Aurora em uma conta de hospedagem sua. Ele não solicita senhas da faculdade e não envia dados para nenhum servidor.

Você precisará de uma conta Cloudflare gratuita e poderá precisar registrar um aplicativo de acesso em Google Cloud ou Microsoft Entra. Algumas universidades exigem consentimento administrativo.

Preparar hospedagem individual

Informe o endereço público do repositório Aurora no GitHub, quando ele estiver publicado. O link abrirá o processo oficial de implantação na Cloudflare.

Entrar na Cloudflare

Este assistente não foi conectado a um repositório público publicado. Antes do uso, indique um repositório GitHub REAL que contenha o projeto. A implantação pode exigir confirmação de recursos. O deploy não configura automaticamente as permissões de Gmail ou Outlook.

Criar os segredos da sua instância

Gere duas chaves exclusivas. Copie-as para os campos de secrets da sua instalação. Não envie essas chaves ao chat, nem as publique no GitHub.

Guarde a senha em um gerenciador de senhas. As chaves não ficam armazenadas neste instalador; ao fechar a página, serão perdidas.

Conectar o e-mail pela API oficial

Na plataforma do provedor, registre um aplicativo OAuth autorizado. Isso pode exigir permissão da faculdade.

Credenciais Google CloudAplicações Microsoft Entra

Registre estes endereços de redirecionamento apenas no provedor selecionado e configure os client IDs/secrets na hospedagem.

Nenhuma tela deste instalador pode conceder aprovação institucional automaticamente.

Concluir a configuração

Estas etapas externas precisam de confirmação no serviço oficial; o assistente não consegue verificá-las sozinho. Depois de implantar o Worker, aplicar as migrações D1 e configurar OAuth, abra o Aurora. Dentro dele você escolherá Gmail ou Outlook e autorizará o acesso na página oficial.

  1. Instância Cloudflare implantada e banco migrado.
  2. PUBLIC_ORIGIN e segredos configurados.
  3. Aplicativo OAuth registrado e callbacks aprovados.
  4. Conexão autorizada no Aurora.
  5. Teste de sincronização e calendário revisado.
